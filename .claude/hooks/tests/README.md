# Пробы стражей

Каждый хук сдаётся с двусторонней проверкой: он обязан краснеть на нарочно
внесённом нарушении и молчать на исправной работе. Вторая половина важнее
первой — страж, срабатывающий на верном ответе, хуже отсутствующего, потому
что его вывод перестают читать оба.

Запуск — по одной или всеми сразу:

```
python3 .claude/hooks/tests/проба_html_guard.py
python3 .claude/hooks/tests/проба_probe_guard.py
python3 .claude/hooks/tests/проба_response_guard.py
```

`проба_response_guard.py` прогоняет не только собранные примеры, но и
двенадцать последних содержательных ответов из настоящей стенограммы: так
видно, шумит страж или находит дело.
