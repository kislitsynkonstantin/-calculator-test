Проверка спецификации по скиллу — что берётся кодом прямо сейчас

Скилл написан под комплект PDF: спецификация, планировка, договор. В калькуляторе вместо PDF лежит сам расчёт — выбранные опции с идентификаторами, примечания, реквизиты, платёжный план. Поэтому часть пунктов проверяется точнее, чем по документу, а часть не проверяется вовсе: планировки в расчёте нет. Ниже — разбор по пунктам скилла.

Два вопроса, которые всплыли при разборе.
1. В базовой комплектации стоят окна «Rehau профиль Blitz 60», а скилл требует профиль не ниже 70 Grazio. Правило сработает на каждом расчёте, где окна не поменяли. Это верно или базу надо поднять до 70?
2. Купели, бассейна, перголы, вентвыходов и парапетов в каталоге опций нет — они появляются только ручными строками. Проверки по ним будут смотреть ручной текст, и точность там ниже.
Скилл v1.17, чек-лист v4.7. Разбор сделан по каталогу из 243 опций и по состоянию расчёта, которое калькулятор уже умеет сохранять.
